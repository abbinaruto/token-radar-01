The model

ln(implied value) = 7.9295 + 0.4617 × ln(TVL) + 0.25 × clamp(7d change, −60%, +120%) / 100

Value grows sublinearly with TVL: doubling TVL lifts implied value by about 38%. The 7-day tilt is small on purpose — one hot week should not decide a launch value. Age was tested and left out: it made held-out predictions worse, so it sets the farm plan's hold length instead.
