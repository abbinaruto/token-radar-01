The model

ln(launch value) = 9.8108 + 0.3902 × ln(TVL) − 0.5463 × ln(min(chains, 5) + 1)

Value grows sublinearly with TVL: doubling TVL lifts launch value by about 31%. A protocol spread over many chains is worth less per dollar of TVL — its TVL double-counts bridged assets — so the chain count enters with a negative coefficient, capped at five chains because the sixth adds no signal. Implied value is launch value × token odds, where the odds are the chance of a token within 24 months from a logistic model on the snapshot's own 447 stand-alone peers (years listed, TVL, 7-day growth), turned into a forward probability with (F(age+2) − F(age)) / (1 − F(age)). Odds fall with age: a protocol that has run three years with no token is less likely to launch next than one that has run three months.

Out-of-sample evidence — the value model

A term is kept only if it lowers the held-out miss on both the leave-one-out test and the walk-forward test (tokens listed earlier price those listed later). The control term — another row's 7-day growth — is the tripwire: it looks harmless leave-one-out and wrecks the walk-forward test, which is why the walk-forward test is the one the model has to pass.
